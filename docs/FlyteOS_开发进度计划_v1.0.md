# FlyteOS 智能飞行管理系统 — 项目开发进度计划

> 版本：v1.0
> 日期：2026-06-23
> 制定依据：《全球无人机飞控系统与适航认证对标调研报告》(FLYTEOS-BM-2026-001)
> 目标：从"飞控基础设施平台"升级为"无人系统研发与验证平台"

---

## 一、战略定位回顾

**对标对象**：Anduril Lattice OS（Web 云原生指挥舱）
**核心原则**：不在飞控算法上与 DJI/Skydio 硬碰硬，聚焦"云原生 GCS + 智能任务管理"
**终极目标**：无人系统研发与验证平台（含仿真、测试、适航、部署全链路）

## 十一、开发规范

### 代码规范
- **前端**：TypeScript 严格模式，ESLint + Prettier，组件级单元测试（Vitest）
- **仿真/算法**：Python 3.11+，类型注解全覆盖，pytest 测试框架
- **提交规范**：Conventional Commits（feat/fix/docs/refactor/test）

### 分支策略
- `main`：生产分支，仅通过 PR 合入
- `develop`：开发主线
- `feature/Mx-xxx`：功能分支，按里程碑编号命名
- `hotfix/xxx`：紧急修复

### 审查要求
- 所有 PR 需 ≥ 1 人 Review 通过
- P0 功能需 ≥ 2 人 Review
- 涉及 Cesium 渲染变更需附带性能对比截图

### 文档要求
- 每个里程碑完成需更新 CHANGELOG.md
- P0 功能必须有架构设计文档（ADR）
- API 变更必须同步更新接口文档
