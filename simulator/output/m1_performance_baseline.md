## 2. 详细指标

### 2.1 渲染帧率 FPS

| 指标 | 值 |
|------|-----|
| 采样点数 | 30 |
| **Min** | 56.1 |
| **Avg** | **58.2** |
| **Max** | 60.1 |
| **P1** | 56.3 |
| **P99** | 60.0 |

> Cesium 渲染管线 + 8 面板 DOM 更新未造成明显帧率下降。requestAnimationFrame 回调链在 30 秒采样周期内保持稳定 ≥56 FPS，远高于 30 FPS 最低交付标准。

### 2.2 EventBus 事件吞吐

| 指标 | 值 |
|------|-----|
| 总 emit 次数 | 4,570 |
| 吞吐 (rps) | **152.3** |
| **延迟 Min** | 0.08 ms |
| **延迟 Avg** | **0.42 ms** |
| **延迟 Max** | 2.31 ms |
| **延迟 P99** | 1.84 ms |

> 每次 `data:update` 事件（5Hz → 150 次/周期）触发 8 面板订阅者同步回调，平均延迟 0.42ms。P99 延迟在 2ms 以内，表明事件分发链路无阻塞瓶颈。

### 2.3 StateManager 读写延迟

| 操作 | 次数 | Min | Avg | Max | P99 |
|------|------|-----|-----|-----|-----|
| **set()** | 6,240 | 0.005 ms | **0.018 ms** | 0.89 ms | 0.12 ms |
| **get()** | 18,720 | 0.001 ms | **0.003 ms** | 0.15 ms | 0.01 ms |

> StateManager 基于内存 Map 实现，读写均为 O(1)，延迟在微秒级别。set() 因触发 `state:changed` 事件广播略高于 get()，但仍在亚毫秒范围。

### 2.4 MAVLink 消息速率

| 指标 | 值 |
|------|-----|
| 总消息数 | 750 |
| 平均速率 | **25.0 msg/s** |
| Min | 25 |
| Max | 25 |

> DataSimulator 在 5Hz 更新频率下，每次 `data:update` 循环广播 5 条 MAVLink 消息（HEARTBEAT / SYS_STATUS / ATTITUDE / GLOBAL_POSITION_INT / GPS_RAW_INT），合计 **25 msg/s**，远高于 MAVLink 标准遥测 10 msg/s 的最低要求。

### 2.5 内存使用

| 指标 | Min | Avg | Max |
|------|-----|-----|-----|
| 已用堆 (MB) | 39.2 | **42.8** | 47.5 |
| 总堆 (MB) | 45.1 | 48.6 | 53.0 |
| 堆上限 (MB) | — | — | 4,096 |

> 30 秒测试期间内存增长约 8MB，无明显内存泄漏趋势。Cesium 3D 纹理/几何缓存为主要内存消费者，8 个 DOM 面板额外占用约 5-8MB。

## 5. 优化建议

| 优先级 | 建议 | 说明 |
|--------|------|------|
| 🟢 低 | 面板 DOM 更新批量合并 | 当前 8 面板独立监听 `data:update` 各自 DOM 操作，可引入 `requestAnimationFrame` 批量提交机制，降低 layout thrashing |
| 🟢 低 | Cesium entity 池化复用 | 频繁创建/销毁 Cesium Entity 会产生 GC 压力，建议使用 Object Pool |
| 🟡 中 | 引入 Web Worker | DataSimulator 噪声生成（Box-Muller 变换 × 8 通道）可迁移至 Worker 线程，释放主线程 |
| 🟢 低 | EventBus 增加优先级队列 | 当前为 FIFO 同步广播，关键事件（如 `health:critical`）可抢占低优事件 |
